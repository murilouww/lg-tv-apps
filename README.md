# lg-tv-apps

Repositório pessoal para a **Homebrew Channel** (LG webOS).

Na TV: Homebrew Channel → Configurações → **Add repository** →

```
https://raw.githubusercontent.com/murilouww/lg-tv-apps/main/apps.json
```

| App | Versão | O que faz |
|---|---|---|
| Tela Brasil | 1.0.0 | Abre o Tela Brasil (streaming público do MinC) em tela cheia na TV. Login com gov.br. |
| Teclado TV | 1.0.0 | Digite pelo celular ou PC nos campos de texto da TV (escaneie o QR). Funciona em apps instalados por fora; tradução PT-BR do webos-tv-keyboard. |

O Teclado TV é uma tradução para PT-BR do projeto [lfkdsk/webos-tv-keyboard](https://github.com/lfkdsk/webos-tv-keyboard) (licença MIT).
